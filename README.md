# SwarupLab

Small, practical developer tools built while learning software development.

This repository is intentionally straightforward. I want each tool to solve a useful problem, keep its implementation understandable, and improve over time instead of filling the project with features just for the sake of having them.

## Current tools

- JSON Formatter
- Regex Tester
- Markdown Preview
- UUID Generator
- Base64 Encoder
- Prompt Notes

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Project direction

The next useful additions will be chosen from real development needs. Possible areas include an API client, JWT inspection, webhook testing and better documentation.

## Principles

- Don't claim a feature that isn't implemented.
- Don't put secrets in client-side code.
- Keep small utilities local when possible.
- Prefer readable code over clever code.
- Add a tool because it is useful, not because the list needs another item.
