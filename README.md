# SwarupLab

> A focused open-source developer workspace for APIs, data, code, documentation and AI-assisted development.

## Why this project?

SwarupLab is designed as a real developer product rather than a collection of unrelated mini-tools. The roadmap focuses on practical workflows developers repeatedly use while building and debugging software.

### Current foundation
- React + Vite
- Responsive dark developer UI
- JSON Studio
- Regex Lab
- Markdown Studio
- JSON → TypeScript Schema Generator
- Modular tool architecture

### Roadmap
- REST API Client with environments, headers, params and history
- HTTP/Webhook inspection
- JWT Inspector
- Code formatting
- API response analyzer
- Secure local environment manager
- AI Dev Assistant with provider abstraction
- Unit/integration tests
- GitHub Actions CI
- Accessibility and keyboard navigation
- Documentation site
- Releases and changelog

## Development

```bash
npm install
npm run dev
npm run build
```

## Philosophy

- Never claim functionality that is not implemented.
- Prefer local processing for sensitive developer data.
- Keep provider/API credentials out of the frontend.
- Build small modules that can be tested and maintained.
- Document limitations clearly.
