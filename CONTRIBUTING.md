# Contributing

Thanks for taking a look at SwarupLab.

## Good contributions

- Fix a real bug
- Improve accessibility or mobile behavior
- Add a useful test
- Improve documentation
- Add a small developer tool with a clear use case

Please explain what the change does and how you tested it.

## Before opening a pull request

- Run `npm run build`
- Don't commit API keys, passwords or `.env` files
- Keep unrelated changes out of the PR
- Update the README if the public behavior changes
