# Contributing to SwarupLab

Thanks for helping improve SwarupLab.

## Before opening a PR
- Explain the problem and proposed solution.
- Keep changes focused.
- Avoid committing secrets or API keys.
- Add or update tests when behavior changes.
- Update documentation when a feature changes.

## Commit style
Use concise messages such as:
- `feat: add jwt inspector`
- `fix: handle invalid json`
- `docs: update api client guide`

## Pull requests
Please include:
1. What changed
2. Why it changed
3. How it was tested
4. Screenshots for UI changes
